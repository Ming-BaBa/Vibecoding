# PRD：内容工坊

> 输入一个主题，自动完成「研究→写文→配图→多平台适配→一键发布」全流程
> 版本：v1.0 | 日期：2026-06-07

---

## 一、一句话定位

**输入主题，自动产出 6 个平台可发布的文章 + 配图，一键复制发布。**

---

## 二、全流程流水线

```
┌──────────────┐
│ ① 输入主题    │  用户提供一句话主题，如"2026年AI产品经理求职指南"
│   Topic       │
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ ② AI 研究采集 │  WebSearch + WebFetch 抓取：
│   Research    │  • 相关公众号文章/知识点
│               │  • 行业报告/数据
│               │  • 大咖访谈/公开言论
│               │  • 大厂分享/技术文档
│               │
│               │  输出：研究笔记.md（结构化素材文档）
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ ③ 整理成文    │  自然叙事skill 将素材转为文章
│   Write       │  • 去文档化、去AI味
│   [自然叙事]   │  • 第一人称叙事，专业自媒体风格
│               │
│               │  输出：文章版.md（定稿）
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ ④ 生成配图 🎨 │  配图skill 为文章生成 3 张二次元Q版插画
│   Illustrate  │  • 基于文章内容自动选场景
│   [配图skill]  │  • 图片插入文章版.md 对应位置
│               │  • 输出：配图/ 文件夹 + 更新的文章版.md
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ ⑤ 多平台适配   │  AI 为每个平台生成独立 .md 文件
│   Adapt       │  ┌──────────┬──────────────────────┐
│   [对话驱动]   │  │ 微信公众号 │ 内联样式HTML          │
│               │  │   知乎    │ 简化HTML             │
│               │  │   掘金    │ MD原文（直接用文章版）  │
│               │  │  小红书   │ 笔记体：短句+emoji+标签 │
│               │  │  人人PM   │ 长文+推荐语+署名       │
│               │  │  CSDN    │ 标准HTML              │
│               │  └──────────┴──────────────────────┘
│               │  输出：文章版-平台名.md × N
└──────┬───────┘
       │
       ▼
┌──────────────┐
│ ⑥ 一键发布    │  preview.py 打开浏览器
│   Publish     │  • 下拉切换各平台版本
│               │  • 预览渲染效果
│               │  • 点 [📋 复制] → HTML+图片base64 进剪贴板
│               │  • 打开平台后台 → Ctrl+V → 发布
└──────────────┘
```

## 三、生图时机

**定在步骤④，整理成文之后。**

理由：
- 文章定稿了才知道该画什么——场景选取依赖完整内容
- 一套图所有平台共用，不需要每个平台单独生图
- 小红书笔记版虽然格式不同，但用同一套图，只是排版顺序可能调整

---

## 四、各环节输入/输出

| 环节 | 输入 | 输出 | 谁来做 |
|------|------|------|--------|
| ① 输入主题 | 用户一句话 | 主题 + 写作角度确认 | 对话 |
| ② 研究采集 | 主题 | `研究笔记.md`（素材文档） | WebSearch + WebFetch |
| ③ 整理成文 | `研究笔记.md` | `文章版.md` | 自然叙事skill |
| ④ 生成配图 | `文章版.md` | `配图/` 3 张图 | 配图skill |
| ⑤ 多平台适配 | `文章版.md` | `文章版-{平台}.md` × N | AI 对话 |
| ⑥ 一键发布 | 平台 .md 文件 | 剪贴板 → 平台后台 | preview.py |

## 六、一次完整对话示例

```
用户：帮我写一篇"2026年AI产品经理求职指南"

Claude：
  好的，先采集素材。
  [WebSearch × 5: 脉脉报告、36氪、招聘数据、大咖观点]
  [WebFetch × 3: 详细页面]
  → 已生成 研究笔记.md（2,340 字素材）

用户：开始写文章

Claude：
  [调用自然叙事skill]
  → 已生成 文章版.md（3,847 字）

用户：配图

Claude：
  [调用配图skill]
  → 已生成 3 张配图，文章已更新引用

用户：生成微信公众号版、小红书版、人人PM版

Claude：
  → 已生成 文章版-微信公众号.md
  → 已生成 文章版-小红书.md（笔记体，847 字 + 5 个话题标签）
  → 已生成 文章版-人人PM.md（含推荐语和署名）

用户：python3 preview.py
  → 浏览器打开，下拉切换各版本，逐个复制发布
```

## 七、涉及的 Skills

| Skill | 用途 | 环节 |
|-------|------|------|
| 自然叙事skill | 结构文档 → 自然人写文章风格 | ③ |
| 配图skill | 为文章生成 3 张二次元Q版插画 | ④ |
| preview.py | 本地预览 + 文件切换 + 复制 HTML | ⑥ |

不需要新增 skill。研究采集用 WebSearch + WebFetch 原生能力。平台适配用对话驱动，不单独封装。

---

## 八、验收标准

| 编号 | 验收项 | 通过条件 |
|------|--------|---------|
| AC1 | 主题→文章 | 输入主题，产出可发布的文章版.md |
| AC2 | 研究素材可追溯 | 研究笔记.md 包含信息源链接 |
| AC3 | 自然叙事 | 文章读起来像专业作者写的，无 AI 套话 |
| AC4 | 配图自动生成 | 3 张图与文章内容对应，风格一致 |
| AC5 | 多平台覆盖 | 至少生成微信/知乎/小红书/人人PM 4 个版本 |
| AC6 | 格式正确 | 微信公众号版粘贴后排版和图片完整显示 |
| AC7 | 一键复制 | 点复制→打开平台后台→Ctrl+V→可发布 |
